## 📁 Portafolio de Proyectos

### 🤖 Robótica y Hardware (Grupo E.R.A.)

* **🔋 E.R.A. Source - Fuente Regulable**
    * *Descripción:* Fuente de alimentación regulada y estabilizada diseñada de forma analógica para el laboratorio del grupo de robótica, garantizando energía limpia y segura para prototipos.
    * *Tecnologías:* Diseño analógico, regulación de potencia, simulación de circuitos.
    * 👉 _[Ver repositorio en GitHub](https://github.com/Azazel-bt/E.R.A.-Source)_

* **⚖️ Robot Clasificador de Pesos**
    * *Descripción:* Sistema de automatización basado en el microcontrolador **ESP32** para identificar, calibrar, clasificar y separar objetos dinámicamente mediante lecturas precisas de peso[cite: 80, 88].
    * *Tecnologías:* ESP32, sensores de peso/celdas de carga, servomotores, calibración analógica-digital[cite: 81, 88].
    * 👉 _[Ver Proyecto (Próximamente)](#)_

* **🐝 Bumblebee - Seguidor de Línea Básico**
    * *Descripción:* Robot móvil autónomo de pruebas diseñado para el seguimiento de trayectorias a alta velocidad mediante sensores ópticos infrarrojos.
    * *Tecnologías:* Control de motores, sensores infrarrojos, Arduino, LCD.
    * 👉 _[Ver repositorio en GitHub](https://github.com/Azazel-bt/Bumblebee-Seguidor-Linea)_
 
* **🦾 Robot-DH-Interactivo-6DOF - Simulador de Brazo Robótico**
    * *Descripción:* Simulador interactivo en 3D de un brazo manipulador de 6 grados de libertad para el cálculo cinemático directo en tiempo real mediante la convención Denavit-Hartenberg.
    * *Tecnologías:* MATLAB, UI Figures, Matrices de Transformación Homogénea, Cinemática Directa.
    * 👉 _[Ver repositorio en GitHub](https://github.com/Azazel-bt/Robot-DH-Interactivo-6DOF)_
 
* **🎯 Simulador-de-Tiro-Parabolico-con-Control-PID-en-Tiempo-Real-MATLAB**
    * *Descripción:* Simulador interactivo en tiempo real que implementa un controlador PID para ajustar el ángulo de disparo de un cañón y acertar a un blanco móvil, permitiendo modificar parámetros físicos y ganancias de control.
    * *Tecnologías:* MATLAB, Control PID, UI Figures, Física de Tiro Parabólico, Sistemas de Control.
    * 👉 _[Ver repositorio en GitHub](https://github.com/Azazel-bt/Simulador-de-Tiro-Parabolico-con-Control-PID-en-Tiempo-Real-MATLAB-)_
 
* **🎯 Sistema-de-Parqueadero-Inteligente-con-ESP32-e-Interfas-grafica**

    *  *Descripción:* Proyecto IoT basado en ESP32 para la automatización y monitoreo en tiempo real de un parqueadero de 4 plazas, utilizando sensores de efecto Hall analógicos, servomotores para control de barreras y un servidor web
   integrado con interfaz interactiva.

    *  *Tecnologías:* ESP32, Arduino, HTML5/JavaScript (AJAX), Servomotores SG90, Sensores Hall (49E), Servidor Web Wi-Fi (Access Point).

    * 👉 _[Ver repositorio en GitHub](https://github.com/Azazel-bt/Simulador-de-Tiro-Parabolico-con-Control-PID-en-Tiempo-Real-MATLAB-)_

### 🧠 Inteligencia Artificial & Machine Learning (Grupo CPS)

* **👁️ Clasificación de Imágenes con Redes Convolucionales (CNN)**
    * *Descripción:* Investigación e implementación de funciones de activación **ReLU** y **Leaky ReLU** en redes neuronales convolucionales profundas utilizando el dataset estándar **CIFAR-10** para clasificación de imágenes. Incluye análisis experimental de mapas de activación (*Feature Maps*) y el impacto de inicializaciones de pesos subóptimas (*Bad Init*) capa por capa.
    * *Tecnologías:* Python, Deep Learning, Procesamiento Digital de Imágenes.
    * 👉 _[Ver Proyecto en GitHub](https://github.com/Azazel-bt/Clasificacion_de_Imagenes_con_Redes_Convolucionales_-CNN-)_

* **🎙️ Clasificador de Voz por Señales de Audio**
  * *Descripción:* Proyecto de Procesamiento Digital de Señales (DSP) y Machine Learning para la conversión, filtrado digital (Butterworth) y clasificación de patrones de voz de diferentes usuarios.
  * *Tecnologías:* Python, Librosa, PyDub, SciPy, Scikit-Learn (SVM), FFmpeg.
  * 👉 _[Ver repositorio en GitHub](https://github.com/Azazel-bt/Clasificador-de-Voz-DSP)_
